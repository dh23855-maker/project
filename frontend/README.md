# frontend 사용법

상담사가 쓰는 화면입니다 (React + Vite). 모든 명령은 `frontend` 폴더에서 실행합니다.

## 실행

화면을 쓰려면 **서버(backend)와 화면(frontend) 두 개를 모두** 켜야 합니다.

### 가장 쉬운 방법

프로젝트 맨 위 폴더의 **`start-dev.cmd`를 더블클릭**하세요. 검은 창 두 개(backend, frontend)가 열리고 잠시 뒤 브라우저가 자동으로 열립니다. 끌 때는 검은 창 두 개를 닫으면 됩니다.
(처음 한 번은 `frontend` 폴더에서 `npm install`을 해야 하고, `backend`는 `backend/README.md`의 "처음 한 번"을 마쳐야 합니다.)

### 직접 켜는 방법 (터미널 두 개)

```
# 터미널 1: backend 폴더
.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --reload

# 터미널 2: frontend 폴더
npm install        # 처음 한 번
npm run dev        # 브라우저가 자동으로 열립니다
```

자동으로 열리지 않으면 브라우저 주소창에 http://localhost:5173 을 직접 입력하세요. 개발 서버가 `/api` 요청을 `127.0.0.1:8000`(서버)으로 넘겨 주므로 로그인이 그대로 동작합니다.

연습용 계정은 `backend/README.md`를 보세요 (kim / park / lee).

### 안 열릴 때

| 증상 | 원인과 해결 |
|---|---|
| `npm.ps1을 로드할 수 없습니다 … 스크립트를 실행할 수 없으므로` | Windows PowerShell이 스크립트 실행을 막고 있습니다. `npm run dev` 대신 **`npm.cmd run dev`** 로 실행하거나, 터미널을 **명령 프롬프트(cmd)** 로 바꾸세요. 또는 `start-dev.cmd`를 쓰세요. |
| `Could not read package.json` / `ENOENT` | 폴더를 잘못 잡았습니다. `frontend` 폴더 안에서 실행하세요. |
| `'vite'은(는) 내부 또는 외부 명령이 아닙니다` | 처음 한 번 `npm install`을 하지 않았습니다. |
| 화면은 열리는데 로그인 화면에 "서버에 연결하지 못했습니다" | 서버(backend)가 꺼져 있습니다. backend도 켜세요. |
| `Port 5173 is already in use` | 이전에 켠 화면 서버가 아직 떠 있습니다. 그 창을 닫고 다시 켜세요. |

## 화면

| 주소 | 화면 | 하는 일 |
|---|---|---|
| `/login` | 로그인 | 아이디·비밀번호 |
| `/` | 상담 | 받은 문의(상태 탭·정렬·너비 조절, CSV로 여러 개 올리기), 문의 내용, 분류 결과와 확신도, 답장 초안, 규정 문서(하나도 참고하지 못하면 "규정 문서에는 없음"), 위험 표현 경고, 승인·수정·재작성·직접 작성, 빠른 승인(승인 대기 탭 메뉴), 다음 문의 자동 이동, 비슷한 지난 문의, 새 문의 입력 |
| `/logs` | 작업 기록 | 누가·언제·무엇을 했는지. 상담사와 행동으로 거르기(선택 메뉴) |
| `/stats` | 문의 현황 | 기간(오늘·7·14·30일, 직접 지정 캘린더), 요약, 날짜(시간대)별 문의 종류 쌓은 막대 그래프(마우스를 올리면 건수), 종류별 합계, 규정 문서에는 없음 비율, 확신도가 낮은 문의 비율, 처리 현황, 표로 보기 |
| `/evaluation` | 성능 평가 | [평가 실행]으로 분류 모델 평가, 전체·종류별·난이도별 정확도, 헷갈린 부분, 틀린 문의, 이전 실행 결과 다시 보기 |
| `/settings` | 설정 | 기준값 변경, 위험 표현 목록 보기·추가 |

로그인하지 않으면 어느 주소든 로그인 화면으로 갑니다. 승인한 답장은 고객에게 실제로 발송되지 않습니다.

## 시험과 빌드

```
npm test           # 화면 시험 (서버와 OpenAI는 가짜로 대신하므로 서버가 꺼져 있어도 됩니다)
npm run build      # 배포용 빌드 (dist 폴더, Git에 올리지 않음)
```
